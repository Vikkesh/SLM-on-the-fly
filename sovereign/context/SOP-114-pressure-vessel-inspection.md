# SOP-114: Pressure Vessel In-Service Inspection

Applies to: all Class A and Class B pressure vessels in the Crude Distillation, Hydrotreater and
Utilities units. Reference: IBR 1950 Reg. 391, API 510.

## 3. Acceptance limits

| Parameter | Limit | Action if exceeded |
| --- | --- | --- |
| Shell wall thickness loss | < 10% of nominal | Fitness-for-service assessment (SOP-118) |
| Operating pressure | <= MAWP on nameplate | Immediate de-rate, notify Shift Superintendent |
| Relief valve set pressure drift | +/- 3% of set point | Re-calibrate within 7 days |
| External corrosion | No pitting > 1.5 mm | Blast and recoat, re-inspect in 6 months |
| Nozzle weld cracks | None permitted | Remove from service until repaired |
| Insulation damage | No exposed metal | Repair within 30 days |

## 4. Inspection frequency

Class A (hydrogen / sour service): every 24 months. Class B: every 48 months. Any vessel
returned to service after repair: inspect within 90 days.

## 5. Approval note

Every inspection closes with an Inspection Approval Note signed by the Inspector, the Area
Engineer and the Approving Officer. Recommendation must be one of: Approved for continued
service; Approved with conditions; Not approved - corrective action required. A High risk
rating always maps to "Not approved" unless a written deviation from the Chief Inspector exists.

## 6. Risk rating

- Low: all parameters within limits.
- Medium: one parameter outside limits with no safety implication in the next 90 days.
- High: any parameter with immediate safety implication, or two or more parameters outside limits.
